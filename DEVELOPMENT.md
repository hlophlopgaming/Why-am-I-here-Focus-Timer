# «Зачем я здесь?» 1.0.0

Расширение для настольного Firefox 140+. Manifest V3, event page, без npm-зависимостей, сборщика, сервера и аналитики. Весь код включён в архив. Для использования см. START-HERE.html.

## Устройство

- `core.js`: нормализация доменов, сопоставление, валидация настроек и длительности, формат времени.
- `background.js`: последовательная очередь операций, сохранение настроек и сессий, browser.alarms, предупреждение, закрытие и синхронизация вкладок.
- `content.js`: форма и напоминание в закрытом Shadow DOM; Web Audio как резерв звукового сигнала. Пользовательские значения вставляются только через textContent/value.
- `options.html`, `options.css`, `options.js`: настройки, тест звука и активные сессии.
- `sounds/warning.wav`: локальный тройной сигнал. `icons/`: локальные PNG.
- `tests/background.test.cjs`: автоматические проверки на Node 18+ со встроенным node:test и VM. Полного E2E в Firefox эти проверки не заменяют.
- `tools/generate-assets.py`: воспроизводимая генерация иконок и звука (Python 3, Pillow). Для использования расширения запускать не нужно.

В ZIP manifest.json и файлы расширения находятся в корне; в рабочем исходном проекте они лежат в extension/. Тесты и генератор поддерживают обе структуры.

## Проверка

```sh
node --test tests/background.test.cjs
```

В рабочем исходном проекте:

```sh
node --test site-intent/tests/background.test.cjs
```

Сценарии: точные границы доменов, нормализация IDN и вложенных доменов, нечисловое время, одновременный старт, общий дедлайн, вкладки в разных окнах и закреплённые вкладки, переход на другой домен в момент закрытия, одно предупреждение, отключённый звук и резерв, пересоздание фоновой страницы, истёкший сохранённый таймер, закрытие последней вкладки, отключение и удаление сайта, проверка отправителя, преждевременный alarm и резервное закрытие по запросу страницы.

## Семантика

Одна сессия на домен со всеми его поддоменами и портами. Родительские домены убирают из списка дублирующие поддомены. Дедлайн — абсолютная отметка Date.now(), сохраняется в browser.storage.local. В фоновой странице browser.alarms обеспечивает предупреждение и окончание; открытые страницы дополнительно проверяют наступивший дедлайн. Это защищает от замедления обычных JS-таймеров в фоновых вкладках.

Полное закрытие/уход со всех вкладок сайта заканчивает сессию. Новый заход запрашивает новую цель. Принудительного перерыва нет. Отключение через настройки отменяет сессии без закрытия вкладок. Повторный запуск не продлевает уже начатую сессию. Новые настройки предупреждения и прозрачности применяются к текущим сессиям; уже прозвучавшее предупреждение не повторяется.

Состояние восстанавливается при загрузке фоновой страницы. Время сна компьютера входит в лимит, но закрытие может произойти только после пробуждения. API alarms может срабатывать с задержкой; система не является таймером реального времени. Временная установка не переживает полный перезапуск Firefox.

## Границы

Это расширение для Firefox; без изменений манифеста и обработки звука в фоне оно не является расширением Chrome. Доступны обычные HTTP/HTTPS-страницы, за исключением защищённых Firefox доменов. Приватные окна требуют разрешения пользователя. Сайты могут удалять DOM-узлы, перекрывать оверлей полноэкранными элементами или вести себя нестандартно; расширение не является защитой от намеренного обхода пользователем.

Одно предупреждение воспроизводится в фоновой странице из локального WAV. При отказе воспроизведения запрос направляется в одну вкладку сайта (предпочтительно активную). Резервный Web Audio контекст разблокируется при отправке формы. Ограничения автозвука, системная громкость и выключенный звук могут помешать сигналу; закрытие и визуальное предупреждение от звука не зависят.

Перед закрытием адрес вкладки перепроверяется. Между проверкой и самим tabs.remove остаётся неизбежный небольшой промежуток времени — эти API не предлагают атомарное «закрыть, только если URL совпадает». Несохранённые данные могут потеряться по замыслу функции автоматического закрытия.

## Обновление: положение, язык и логотип

- `reminderPosition` хранится отдельно в `browser.storage.local`. Перемещение мышью или стрелками сохраняется через `SAVE_POSITION` и передаётся всем вкладкам. Новые вкладки получают координаты в `GET_STATE`; в маленьком окне блок ограничивается границами экрана без изменения сохранённых координат.
- `config.language`: `auto` по умолчанию — язык интерфейса Firefox через `browser.i18n.getUILanguage()`, с английским для неподдерживаемых языков. Доступны en, ru, de, es, fr, it, pl, zh (упрощённый китайский), hi (хинди), ar, pt и tr. Сохранённый ручной выбор имеет приоритет; старые настройки без языка переходят на auto. Для арабского интерфейс отображается справа налево. Переводы находятся в `i18n.js`; пользовательские цели не переводятся.
- Новый пример цели: учить новый язык или изучать предмет.
- Логотип: `icons/logo.png`; подключённые размеры: `icons/intent-48.png`, `icons/intent-96.png`, `icons/intent-128.png`. Промпт и способ генерации: `icons/LOGO.md`. Старый генератор `tools/generate-assets.py` создаёт прежние `icon-*.png`, не затрагивая новые иконки.
- Проверка: `node --test tests/background.test.cjs`. После обновления временного расширения в `about:debugging` обнови открытые страницы сайтов, чтобы загрузились новые content scripts.


Звуковые сигналы генерируются через Web Audio в `sound.js`: три тона для предупреждения и один для отсчёта. Кнопка проверки использует тот же механизм. WAV-файлы больше не используются при воспроизведении. Ожидание разблокировки звука ограничено 500 мс, чтобы не задерживать обработку таймера; при блокировке в фоне используется существующая отправка сигнала одной вкладке.


## Выбор сайтов

Общий переключатель `enabled` удалён. В обычном режиме работают только домены из `sites`; пустой список отключает напоминания. Старое поле `enabled` игнорируется при миграции, сохранённый список сайтов остаётся.

`allSites` по умолчанию `false`. Его включение в настройках требует подтверждения через системный диалог, затем сохранения настроек. В этом режиме сайты вне списка получают отдельные таймеры по имени хоста (www объединяется с основным хостом); домены из списка по-прежнему включают поддомены. При смене режима неподходящие сессии отменяются без закрытия вкладок.

Обрабатываются только HTTP/HTTPS. Служебные схемы (`about:`, `chrome:`, `moz-extension:`, `file:` и другие) исключены; защищённые сервисы Firefox также исключены в общей функции определения сайта, в том числе из автоматического закрытия вкладок.
